# Ошибки монтажа, которые закрывают правила

Список собран из реальных правок к роликам за три месяца: около 60 замечаний автора к монтажу, который делал Claude. Для каждой ошибки указано, откуда она бралась и что теперь её не даёт.

| Ошибка | Как часто | Откуда бралась | Что не даёт ей повториться |
|---|---|---|---|
| Дубли и запинки не вырезаны: «в этом месте не вырезано», а потом «действительно» | ~10 раз, самая частая | Вся запись расшифровывалась целиком. Расшифровщик склеивал повтор в одну гладкую фразу: в тексте дубля нет, в видео он есть | Расшифровка по кускам на каждой паузе (`transcribe.py`), подсказка с запинками для whisper, решение по каждому куску (`cut.py` не запускается без него), повторная проверка мелкими кусочками (`verify.py`) |
| Оставлен неудачный дубль, вырезан удачный | ~5 раз | Брался первый дубль, а не последний | Правило «последний целый», подсказки ДУБЛЬ / НЕДОГОВОРЁННЫЙ ДУБЛЬ / МЕЖДУ ДУБЛЕМ |
| Вырезано нужное | ~3 раза | Смысловая пауза или единственная версия фразы принималась за мусор | Раздел 3.4 CLAUDE.md, сверка со сценарием: каждое предложение ровно один раз |
| Обрыв на полуслове | ~2 раза | Рез по времени слова из расшифровки, а оно плывёт на 0,1–0,3 с | Границы по громкости (`cut.py`), предупреждение «голос на краю стыка» в `verify.py` |
| Паузы, вдохи, кашель | ~7 раз | Паузы резали по списку жалоб, а не сканом всего ролика; вдох принимался за речь | Все промежутки между оставленными кусками вырезаются; начало куска – по порогу голоса, вдох тише; скан пауз в `verify.py` |
| Пустой кусок после лимита расшифровщика | 1 раз, но спрятал дубли | Упавший кусок считался «без слов» | Упавший кусок не кэшируется, команда падает и просит повторить |
| Лицо мелкое, не видно, закрыто вставкой | ~6 раз | Вставки на весь экран, карточка лица 432×324 | Лицо в каждом кадре, карточка 920×620, уменьшенное лицо – круг от 420 px, кроп по сетке и проверка на трёх моментах |
| Контрольные кадры без лица | постоянно | Лицо накладывалось только при финальном рендере | `--frames` теперь кладёт лицо из исходника в карточку |
| Блёклые цвета с iPhone | ~3 раза | HDR (HLG) читался как обычное видео | `prep.py` распознаёт HDR и переводит через LUT; сверка с галереей телефона |
| Цветокоррекция без просьбы | 2 раза | «Улучшение» картинки по своей инициативе | Цвет не трогать (раздел 6) |
| Звуковые эффекты перекрывают слова | 4 раза | Громкость эффектов «на глаз» | Эффекты только если их требует стиль и всегда тише голоса |
| Субтитры не в такт, первое слово пропадает | 2 раза | Расшифровщик ставит слово раньше реального звука, слово выпадало из куска | `plan.py` прижимает слова к границам оставленных кусков |
| Заглавная буква посреди фразы на стыке дублей | постоянно | Склеены начало одной попытки и конец другой | `plan.py` правит регистр на стыке |
| Вставка не по смыслу («говорю про качество – показываешь выбор стиля») | ~3 раза | Сцены ставились по секундам | Сцены привязаны к словам транскрипта |
| Скриншот с окном cookie или входа | постоянно | Снимок первого экрана как есть | `shot.py` закрывает и убирает окна согласия; правило «смотреть скриншот перед вставкой» |
| Пропадает звук в конце | 2 раза | Звуковая дорожка короче видео после склейки | Склейка одним графом, проверка длины звука и видео |
