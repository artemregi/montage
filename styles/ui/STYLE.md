# Стиль `ui` – «что говорим, то показываем»

Вертикальный рилс 1080×1920. Сверху – живой интерфейс того, о чём сейчас речь. Посередине – одна строка субтитров по 3 слова, текущее слово жёлтое. Внизу – лицо крупной карточкой. Каждая фраза получает своё движение на экране.

Движок: `styles/ui/ui_reel.py`. Под ролик пишется только `plan.json`, код движка не меняется.

---

## 1. Сетка кадра

| Зона | Координаты (px) | Что там |
|---|---|---|
| Графика | x 0–1080, y 0–1160 | интерфейс, скриншот, код, сетка роликов |
| Метка раздела | x 24, y 24 | «● Claude Code», «ПАУЗЫ» жёлтыми капсами |
| Субтитры | центр по x, верх строки y 1186, шрифт 44 px | 3 слова, текущее жёлтое |
| Лицо – карточка (`face: "card"`) | x 80, y 1268, 920×620, скругление 30 | большинство сцен |
| Лицо – на всю ширину (`face: "hero"`) | x 0, y 1280, 1080×640 | интро, первые 2–5 с |

Верхние ~250 px и нижние ~150 px закрывает интерфейс Instagram. Важное (подписи, кнопки) туда не ставить. Метка раздела наверху – исключение, она декоративная.

## 2. Цвета и шрифты

| Токен | Цвет | Где |
|---|---|---|
| фон | `#0A0A08` | весь кадр |
| панели | `#151513`, `#1C1C1A` | окна, карточки, дорожки |
| рамки | `#2A2A27` | обводки панелей |
| акцент | `#FDE445` | единственный акцент: текущее слово, рамки, галочки, кнопка |
| текст | `#F3EFE6` | основной |
| второстепенный | `#8C8A84` | подписи, линейки |
| «плохо» | `#E5484D` | только неудачный дубль и свайп на графике |

Шрифты: Inter (субтитры, метки, кнопки), JetBrains Mono (код, имена файлов), PT Serif (заголовок призыва, подписи к чужим роликам). Без градиентов, свечения и стекла.

## 3. Лицо

- Карточка 920×620, интро 1080×640. Меньше не делать: при «слишком мелко» автор уже возвращал ролик.
- `card_crop` – кроп исходника в пропорции 1,48 (920:620). Для вертикального видео 1080×1920 это ширина 1080 и высота ~728. Голова занимает 55–70 % высоты кропа, глаза на 35–40 % от верха, подбородок целиком.
- `hero_crop` – пропорция 1,69 (1080:640): 1080×640 из вертикального исходника.
- Подбор и проверка – `CLAUDE.md`, раздел 5. Под лицом не должно оставаться пустой полосы.
- `face: "none"` – только для коротких вставок до 1,5 с.

## 4. Субтитры

- Окно 3 слова, разрыв после точки и вопроса. Обычный регистр, пунктуация сохраняется.
- Текущее слово жёлтое, остальные белые. Без подложки, без обводки, без анимации – переключение по слову.
- Исправления слов – `plan.json → fix`: `{"Клод": "Claude", "еще": "ещё"}`. Ключ – слово как в расшифровке, с пунктуацией, если она есть («Код.»).

## 5. Ритм: правила, которые автор уже утвердил

1. **Каждой фразе – своё движение.** Не статичный скриншот на 3–4 секунды, а элемент, который появляется точно на слове: печать в терминале, рамка на нужной строке, галочки по сетке, перетаскивание файла, кривая с метками, печать в поле комментария. Новая анимация каждые 1–2 с.
2. **Привязка к словам, не к секундам.** Всё время в сценах (`from`, `at`, `*_at`, `out`) – слово из транскрипта: `"скилл"`, `"ролик#2"` (второе вхождение от начала сцены). Тогда при перемонтаже ничего не съезжает.
3. **Без выдуманных цифр.** Графики – форма и подписи словами. Процентов, просмотров, сумм нет, если их не сказал автор.
4. **Читаемо.** Мелкий скриншот целиком не показывать: `view` / `view_to` наезжают на нужную область.
5. **Призыв живой.** Кодовое слово печатается в поле комментария, кнопка отправки желтеет.
6. **Верх кадра не пустой.** Графика занимает зону y 0–1160 хотя бы на две трети: короткий код – крупнее шрифт или ниже `y`, мало строк – добавить `pops`, скриншот – `box` на всю ширину. Чёрная дыра между графикой и субтитрами – ошибка.
7. **Своё видео вставкой не показывать**, когда внизу и так карточка с лицом: два одинаковых автора в кадре. Кадры из видео – только в `grid`, `takes`, `phone`, `editor`, `chart`.
8. **Скриншот по делу.** `view` наводится на тот блок страницы, о котором говорят (кнопка, заголовок, результат), а не на подвал или политику конфиденциальности.
9. **Начало не пустое.** Первая сцена – сразу движение (сетка роликов со сканером, печать в терминале), лицо `hero`.

## 6. Какую сцену ставить на какую фразу

| Говорит про… | Сцена | Чем наполнить |
|---|---|---|
| свои ролики, «десятки роликов», «прогоняю ролики» | `grid` | кадры из видео (`src:N:card`) или обложки своих рилсов |
| программу, команду, «пишу в Claude», файл с правилами | `code` | строки терминала или файла, ключевое в `{фигурных}` – жёлтым |
| сервис, сайт, «захожу в …» | `app` | скриншот `tools/shot.py`, `view` на нужный блок, курсор с кликом, `pops` рамки |
| запись на телефон, съёмку | `phone` | кадр из видео в телефоне, рамка фокуса, веер карточек |
| монтажку, сборку ролика | `editor` | превью кадрами видео, дорожки, плейхед |
| дубли, паузы, «вырезал лишнее» | `takes` | кадры видео как дубли, плохие краснеют, чистый в центр |
| сравнение, «4 вещи», «референс → свой стиль» | `cards` | 2×2 карточки: картинка, цвета или текст |
| текст промпта, «пишу задание» | `prompt` | абзац, главная фраза `{жёлтым}` и маркером |
| удержание, «где досматривают», прогноз | `chart` | лента кадров + кривая, метки словами |
| «было → стало», видео → анимация | `flip` | слева кадры видео, справа последовательность |
| чужой ролик, пример | `media` | кадр или картинка с подписью антиквой |
| призыв, «напиши слово» | `cta` | заголовок, профиль, комментарий печатается, кнопка |

Поверх любой сцены – `pops`: рамка (`box`), плашка (`pill`), жёлтая плашка (`badge`), галочка (`check`), крестик (`x`) на нужном слове. Большое жёлтое слово поверх сцены – `word`.

## 7. plan.json

`tools/plan.py` создаёт заготовку. Поля:

| Поле | Что |
|---|---|
| `source` | `source.mp4` |
| `transcript` | `transcript_src.json` (создаёт plan.py) |
| `keep_file` | `keep.json` (создаёт cut.py) |
| `card_crop`, `hero_crop` | кропы лица `[x, y, w, h]` по исходнику |
| `fix` | исправления слов в субтитрах |
| `out` | имя готового файла |
| `jobs` | сколько процессов рендера (6; на слабом ноутбуке 3) |
| `scenes` | сцены по порядку |

Общие поля сцены: `from` (слово начала, у первой сцены `0`), `type`, `face` (`card` по умолчанию, `hero`, `none`), `label {text, kind: dot|dotl|head}`, `word {text, at, out}`, `pops`. Конец сцены – начало следующей.

Картинки: путь от папки проекта (`assets/site.png`) или кадр из самого видео `"src:12.5:card"` – кадр склейки на 12,5 с, кроп `card` (лицо), `wide` (весь кадр), `tall` (9:16 из горизонтального).

### Поля сцен

| type | Поля |
|---|---|
| `editor` | `previews [{img,at}]`, `panels [{img,x,y,w,h,at,link_at}]`, `thumbs`, `visual [{img,w,at}]`, `blocks`, `text_at`, `text_step`, `cursor` |
| `phone` | `img`, `box`, `focus [x,y,w,h]`, `side [{img,at,x,y,rot}]` |
| `app` | `img`, `box`, `view [x,y,w]`, `view_to`, `chips [{img,name,x,y,at,from_xy,dur}]`, `wave {x,y,n,at}`, `cursor [{x,y,at,click}]` |
| `code` | `lines` (`{жёлтым}`), `tab`, `y`, `type_at`, `cps`, `hl [{line,at}]`, `attach {img,name,at}` |
| `takes` | `imgs`, `names`, `heads [{text,at}]`, `bad [i]`, `bad_at`, `good`, `good_at`, `strip {pauses [[x,w]], pause_at, cut_at}` |
| `grid` | `imgs`, `cols`, `y`, `mark_at`, `scan_at`, `scan_dur`, `checks_at` |
| `cards` | `items [{label, img или swatches или text, at}]`, `y` |
| `prompt` | `text`, `mark_at` |
| `cta` | `title`, `avatar`, `name`, `bio`, `link`, `sub`, `button`, `handle`, `comment {text, at, cps}` |
| `media` | `img`, `box`, `caption`, `cap_at` |
| `chart` | `thumbs`, `draw_at`, `draw_dur`, `marks [{x, label, kind: share|swipe, at}]` |
| `flip` | `video`, `video_fps`, `seq`, `seq_at`, `seq_fps`, `cap_left`, `cap_right` |

Пример готового плана – `styles/ui/example/plan.json` (ролик 31 с, 10 сцен).

## 8. Запуск

```
python3 styles/ui/ui_reel.py projects/<имя>/plan.json --frames 1,3,6,9,12   # контрольные кадры в check/
python3 styles/ui/ui_reel.py projects/<имя>/plan.json                       # рендер, 2–6 минут
```

Контрольные кадры – минимум по одному на сцену: середина сцены и момент, когда появляется главный элемент. Смотреть каждый: лицо на месте и крупное, элемент читается, ничего не обрезано по краям, субтитр не налезает на графику и лицо.

Нужен Google Chrome: кадры рисуются в нём.
